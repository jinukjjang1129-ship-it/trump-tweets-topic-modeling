# 분석 설계 및 검증 범위

## 데이터
- 기간: 2016-11-08 ~ 2019-09-22 (기존 README 기준)
- 트윗 텍스트 및 S&P 500 분봉 가격
- 정규장(RTH) 관측값과 트윗 타임스탬프 정렬이 필요함

## 토픽 모델링
- LDA 20개 토픽을 탐색했으며 연구 과정에서는 토픽뿐 아니라 단어 단위도 검정함.
- 토픽 강도, 단어 선택 및 분석 구간이 데이터 관찰 후 결정되었을 가능성이 있으므로 탐색/확증을 구분해야 함.

## 회귀 분석
- `src/regression.py`: 이벤트 토픽 강도를 독립변수로 사용하는 HuberT RLM.
- 평가 시간 간격: 1, 10, 20, 30, 45, 60, 120분.
- 최소 이벤트 간격 10분은 120분 관측창의 중첩까지 제거하지 않음.
- 코드상 `merge_asof(direction="forward")`에 최대 허용 간격이 없어 시점 정합성 점검 필요.
- p-value 해석 전 다중검정/시계열 의존성/표본 외 재검증 필요.

## 백테스트
- `src/backtest.py`: 이벤트별 60분 수익률을 부호 반전해 단순 누적.
- Buy & Hold는 분봉 open 가격 변화율을 복리 누적.
- 서로 다른 거래 노출, 누적 방식, 표본 시점이므로 동등 비교가 아님.
- 매매 수수료, 스프레드, 슬리피지, 공매도 제약은 반영되지 않음.

## 재현성
- `data/processed/reg_input_price_returns.csv`가 없어 단독 회귀 실행은 불가능.
- `notebooks/`는 실험 원본이며 일부 로컬 절대경로 및 실행 기록을 포함할 수 있음.
- 결과 숫자나 그래프를 포트폴리오에 사용하기 전 실행 환경·원본 데이터와 대조할 것.
