## 실제 확인한 문제

- 기존 백테스트는 DST에 따른 `-04:00/-05:00` 혼합 오프셋을 하나의 timezone으로 파싱하지 않아 실행이 중단됐다. UTC로 파싱한 뒤 NY로 변환하고 시작 날짜도 timezone-aware로 수정했다.
- 기존 회귀 스크립트가 요구하는 `reg_input_price_returns.csv`와 노트북의 중간 Excel은 없다. 기존 스크립트의 정확한 재현은 여전히 불가하다. 새 `event_pipeline.py`는 원본 OHLC를 직접 읽어 다른 명시적 검증 경로를 제공한다.
- 원본 OHLC 1,123,674행 중 시각 중복 56개가 있으며 동일한 OHLC 중복이다. 양수/고가/저가 검사를 통과했다. 원본 트윗 16,924개에 ID 중복은 없다.
- 기존 가공 백테스트의 161,549개 가격은 원본의 naive 시각을 UTC로 취급한 조인과 100% 일치한다. [HistData FAQ](https://www.histdata.com/f-a-q/)는 해당 공급자의 시각을 **DST 없는 EST**로 설명한다. 파일명은 HistData 형식과 일치하나 다운로드 이력·라이선스가 없어 공급자를 확정하지 않는다.
- 기존 `shift(-h)`는 h행 이후를 h분 이후로 취급한다. 주말·야간·결측 분봉이 끼면 다르다. 새 코드는 정확한 시각의 endpoint와 h개 연속 분봉, 동일 NY 날짜를 요구한다.
- 기존 10분 이벤트 간격은 60/120분 수익률의 중복을 막지 못한다. 새 코드는 각 horizon만큼 비중복 이벤트를 선택한다.

## LDA

원형 전처리(URL·멘션 제거, bigram min_count=5/threshold=10, NLTK 불용어, Porter stemming), Gensim seed=42/passes=10/20 topics를 실행했다. 전체 기간의 비어 있지 않은 문서 8,630개, c_v=0.3546, 기존 topic0와 8,093분을 비교한 상관계수 0.9181, MAE 0.02042다. **기존 확률을 정확히 재현한 것은 아니다.** 과거 환경 lock, 모델, 불용어 버전이 없어 차이 원인의 기여도를 확정할 수 없다. 재실행 토픽0의 주요 단어 china/tariff는 기존 해석과 부합한다.

기존 노트북에는 20개 모델의 coherence 계산이 있으나 후보 토픽 수 비교의 실행 근거가 없다. 별도 실험에서는 2018-09-01 이전에만 bigram·어휘·모델을 학습하고 학습 c_v로 후보를 비교했다.

| 토픽 수 | 학습 c_v |
|---|---:|
| 10 | 0.39749 |
| 20 | 0.38640 |

단일 시드이며 토픽 안정성과 사람의 해석 품질을 보장하지 않는다. 선택된 10개 모델에서 tariff/china/trade의 확률 질량으로 토픽을 정했으나 일반적인 정치·경제 단어도 섞인다. 이를 과거의 Trade War 토픽과 동일한 토픽으로 간주하지 않는다. 이 실험은 미래 수익률로 토픽을 고르지 않는다.

## 실행 규칙과 통계

- 트윗은 UTC를 유지한다. `ceil(minute)+1분`에 진입한다. 데이터의 초 단위 해상도 부족을 실행 지연으로 보완하되 실제 체결 가능성을 보증하지 않는다.
- NY 평일 09:30~16:00만 사용한다. 이는 거래소 휴장·조기 폐장 달력 검증을 대체하지 않는다.
- exact join으로 주말·다음날로 이벤트를 넘기지 않는다. 청산까지 분봉이 비어 있으면 제외한다. 이 완전구간 필터는 사후 데이터 가용성 검사이며 실제 실행 장애를 모델링하지 않는다.
- 개발/평가 경계는 2018-09-01 UTC다. 이미 과거 연구에서 관찰한 기간이므로 평가 구간은 **진정한 미사용 미래 표본이 아니다**.
- 토픽 회귀: horizon별 중복 제거, 개발 구간에서 평가 경계를 넘는 label 제거, OLS 일자 군집 표준오차. 기존 Huber 회귀와 다른 민감도 검사다.
- 단어 회귀: tariff/china/deal × 7개 horizon × 2기간의 실행 가능한 검정을 일자 군집 표준오차로 분석하고 BH-FDR을 적용한다. 토픽 회귀와 단어 회귀는 각각의 family다. 과거 모든 가설에 대한 보정을 완료한 것은 아니다. HuberT의 기존 p-value 0.005~0.008 재현을 주장하지 않는다.

## 포트폴리오

초기자본 1, 거래 시 절대 명목노출 1배, 거래 사이 고정 주식 수, 현금과 공매도 대금의 회계 처리를 반영한다. 기본 비용은 왕복 2bp(편도 1bp)의 시나리오다. 롱→숏 전환은 명목노출의 2배를 매매한다. 보유기간 동안 차입료·금융비용·실제 호가 스프레드·시장충격은 별도 미반영이다. SPXUSD 피드가 직접 거래 가능한 S&P 500 현물인지 확인되지 않았다.

두 종류를 나눴다.
1. 동일한 이벤트 시각·보유기간에서 롱/숏을 비교하는 matched exposure 진단.
2. 롱을 유지하다 `topic>=개발기간 중앙값`과 tariff가 함께 발생하면 60분 숏으로 전환하는 재구성. 같은 초기자본·목표 절대노출로 롱 보유와 비교하되 실제 방향 노출은 다르다.

원본 전략 주문 내역이 없고 토픽 모델·입출력·기간·비용이 다르므로 숫자가 비슷해도 과거 성과의 재현이 아니다. `result/validation/*/summary.json`의 값만 이번 실행 결과로 사용한다.

## +2.1%p 판정

**원래 주장한 1년 9개월 전략의 +2.1%p는 재현 확인되지 않았다.** 가공 CSV의 2018-09 이후 이벤트 숏 수익률 합은 16.449%, 같은 기간 가격비율 수익률은 3.330%로 차이 13.119%p다. 이는 서로 다른 노출의 계산이며 포트폴리오 비교로 사용할 수 없다. 원본 노트북 그래프의 단순 차감 rebasing도 가격비율 rebasing과 다르다.

재구성 결과가 약 2%p라고 해도 원래 주장한 기간/전략과 일치하지 않는다. 타임존 확인, 원래 전략 정의·거래원장, 비용 근거, 미사용 평가 자료가 필요하다.

## 면접 설명

- HuberT은 극단값 영향을 줄이지만 시간대 오류·중복 표본·다중검정을 해결하지 않는다.
